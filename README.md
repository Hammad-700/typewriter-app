# Typewriter Sounds for Your Laptop

Hey!

I got tired of my silent laptop keyboard, so I made this little app. Now, whenever I type anywhere – in a document, a browser, or a chat – my keyboard clicks like a typewriter.

Each key makes a sound, but Enter, Backspace, and CapsLock have their own special clicks.

---

## How to Use

1. Download the `typewriter.exe` from the [Releases](https://github.com/Hammad-700/typewriter-app/releases) section.
2. Right-click the file and choose "Run as administrator" (this is needed so it works in every app).
3. Start typing! 
4. Press the ESC key when you want to turn it off.

---

## I Want to Change the Sounds

If you want to use your own sounds, replace the MP3 files in the project folder. Just keep the same filenames:
- `default.mp3` for regular keys
- `enter.mp3` for the Enter key
- `backspace.mp3` for the Backspace key
- `capslock.mp3` for CapsLock

---

That's it! Enjoy your new keyboard sounds.
